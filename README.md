⚙ Features:
- Automatically plays a greeting upon startup
- Add custom text for the app to read aloud
- Add your own pre-recorded greeting audio
- Adjust text-to-speech speed and pitch
- Adjust playback volume
- Set intro music or background music for text greetings
- Launch any installed app after the greeting finishes playing
- Auto-update to the latest version

💫 Notes:
- Upon first launch, connect to a local Wi-Fi network
- Some devices may struggle to access existing local greeting files; solution: install a file manager app (e.g., from Play Store: https://play.google.com/store/apps/details?id=me.zhanghai.android.files&hl=vi or https://github.com/zhanghai/MaterialFiles/releases/latest/download/app-release-universal.apk)
- To use with Android Auto, install an intermediary app like MacroDroid, Tasker, or Automate
- Greeting MP3 filenames must use no accents, no special characters, and the lowercase extension ".mp3"
- Some device interfaces/models do not support the automatic startup greeting feature You can install the "Autostart" app on your device (https://t.me/olivergreetly/154/438).
<br><br>
